# قالب مقاله

این پوشه را کپی کنید، نام کپی را شمارهٔ مطلب (مثلاً `004`) بگذارید و آن را در `blog/posts/` قرار دهید.

در هر دو فایل `fa.html` و `en.html` بخش‌های دارای توضیح `EDIT` را تکمیل کنید: خلاصه، عنوان، تاریخ `datetime` و متن مقاله. مقدار `YYYY-MM-DD` باید با یک تاریخ واقعی مثل `2026-10-16` جایگزین شود.

هدر، دکمه‌ها و مسیر فایل‌های مشترک را تغییر ندهید. فایل‌های تصاویر را می‌توانید کنار همین دو فایل یا در زیرپوشهٔ `images` بگذارید. پس از آماده‌شدن، کل پوشه را یک‌جا در GitHub آپلود کنید.

راهنمای کامل و راه‌اندازی اولیه: `blog/README.md` در ریشهٔ پروژه.
