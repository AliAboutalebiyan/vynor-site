# راهنمای دستی بلاگ (بدون ساخت خودکار)

این پروژه هیچ Build خودکار یا GitHub Actions ندارد. همهٔ تغییرات را دستی اعمال و آپلود می‌کنید. این راهنما مراحل دقیق افزودن یک نوشتهٔ جدید است.

## افزودن یک نوشتهٔ جدید (شماره‌دار)

1. از پوشهٔ **`blog/post-template`** یک کپی بگیرید و نام آن را شمارهٔ نوشته بگذارید؛ مثلاً `004` (پس از `003`).
2. در هر دو فایل `fa.html` و `en.html` این موارد را ویرایش کنید:
   - `<title>` — عنوان صفحه در تب مرورگر؛ ساختار «عنوان — وبلاگ واینور» (فارسی) و «Title — vynor Blog» (انگلیسی) را حفظ کنید.
   - `<meta name="description" content="...">` — خلاصهٔ یک‌تکهٔ نوشته در همان زبان.
   - `<h1>` — عنوان اصلی مقاله در همان زبان.
   - `datetime="YYYY-MM-DD"` — تاریخ واقعی نوشته (مثلاً `2026-03-05`)، هم در `<time>` هدر مقاله.
   - متن مقاله داخل `<div class="post-body">` را جایگزین کنید؛ محتوای قالب را حذف کنید.
3. لینک‌های داخل فایل قالب را بررسی کنید: مسیرهای نسبی مثل `../../assets/...` را تغییر ندهید؛ لینک دکمهٔ زبان و canonical از قبل برای هر پوشه درست است.
4. در هر دو فایل، آدرس `canonical` و `hreflang` به همان صفحه اشاره می‌کنند؛ نیازی به تغییر ندارد چون مسیر شمارهٔ پوشه در URL فقط با نام پوشهٔ جدید عوض می‌شود — اگر مسیر کامل نوشته شده، فقط شمارهٔ پوشه را در آن به‌روز کنید.
5. پوشهٔ آماده را با هر دو فایل `fa.html` و `en.html` یک‌جا در `blog/posts/` آپلود کنید.

```text
blog/posts/004/
├── fa.html
├── en.html
└── images/       # اختیاری؛ تصاویر همین مقاله
```

## افزودن دستی کارت به هر دو صفحهٔ فهرست

هیچ فهرستی خودکار ساخته نمی‌شود. پس از آپلود پوشهٔ نوشته، یک `<article class="post-card">` **دستی** به هر دو فایل `blog/fa/index.html` و `blog/en/index.html` اضافه کنید:

1. کارت جدید را **در بالای** لیست کارت‌های موجود داخل `<div id="posts" class="posts-list">` قرار دهید تا ترتیب «از جدید به قدیم» حفظ شود.
2. ساختار کارت (فارسی):

```html
<article class="post-card">
	<h2><a href="../posts/004/fa.html">عنوان مقاله</a></h2>
	<p class="post-meta"><span class="pill date"><time datetime="2026-03-05">2026-03-05</time></span></p>
	<p>خلاصهٔ یک‌خطی مقاله.</p>
</article>
```

3. همین کارت را با `href="../posts/004/en.html"` و متن انگلیسی به `blog/en/index.html` اضافه کنید. عنوان، تاریخ و خلاصهٔ کارت باید دقیقاً با `<h1>`، `datetime` و `description` خود مقاله مطابقت داشته باشد.
4. ترتیب نهایی هر دو فهرست باید یکسان و بر اساس تاریخ واقعی نوشته‌ها از جدید به قدیم باشد (نه بر اساس شمارهٔ پوشه).
5. چیدمان کارت‌ها (کلاس‌ها و تگ‌ها) را بین فارسی و انگلیسی یکسان نگه دارید؛ فقط متن‌ها و `dir` صفحه فرق می‌کند.

## لینک تماس و فوتر

لینک نسبی تماس فارسی در هدر (`../../fa/contact/`) از قبل درست است؛ آن را تغییر ندهید. فقط مسیرهای مشترک (استایل، اسکریپت، favicon) را دستکاری نکنید.

## پیش‌نمایش محلی، اختیاری

برای دیدن نتیجه روی رایانه:

```powershell
cd work/blog
python -m http.server 8766 --bind 127.0.0.1
```

سپس `http://127.0.0.1:8766/blog/fa/` و `http://127.0.0.1:8766/blog/en/` را باز کنید. چون مسیرها نسبی‌اند، همین پیش‌نمایش برای بررسی لینک‌ها کافی است. هیچ فرمان build یا اسکریپت دیگری لازم نیست.
