# vynor.ir — Ali Aboutalebiyan Profile

## انتشار فعلی و افزودن نوشته

انتشار سایت با گردش‌کار `.github/workflows/pages.yml` انجام می‌شود. در GitHub Pages، منبع انتشار را یک‌بار روی **GitHub Actions** قرار دهید. سپس برای نوشتهٔ جدید فقط پوشهٔ شماره‌دار حاوی `fa.html` و `en.html` را در `blog/posts/` آپلود کنید؛ فهرست وبلاگ و نقشهٔ سایت خودکار ساخته می‌شوند.

قالب آماده: `blog/post-template/` — راهنمای کامل: [blog/README.md](blog/README.md).

پیش‌نمایش یا انتشار در هاست دیگری باید از خروجی `_site` ساخته‌شده با `python scripts/build_site.py` انجام شود. دستورهای میزبانی قدیمی در ادامه را روی این خروجی اعمال کنید.

سایت استاتیک و کاملاً مستقل (بدون وابستگی به CDN خارجی) برای برند **vynor** — علی ابوطالبیان.

## زبان‌ها
- نسخه انگلیسی در `en/index.html` و نسخه فارسی در `fa/index.html` قرار دارد. `index.html` در ریشه فقط یک ریدایرکت خودکار به `/en/` است.
- دکمه «فارسی / English» در بالای سایت بین دو نسخه جابه‌جا می‌شود؛ این قابلیت بدون JavaScript هم کار می‌کند.
- نسخه فارسی چیدمان راست‌به‌چپ و فونت B Mitra دارد. فایل فونت در `assets/fonts/BMitra.woff` همراه سایت منتشر می‌شود و نیازی به نصب فونت روی دستگاه بازدیدکننده یا اتصال به CDN ندارد. منبع و مجوز مخزن فونت در همان پوشه نگهداری می‌شوند. فایل‌های CSS و JavaScript بین هر دو زبان مشترک‌اند.
- برای تغییر محتوا، هر دو فایل HTML را ویرایش کنید. ترجمه‌ها مستقل هستند و خودکار همگام نمی‌شوند. قالب فهرست‌های وبلاگ در `blog/en/index.html` و `blog/fa/index.html` قرار دارد و فهرست نوشته‌ها هنگام ساخت از پوشه‌های `blog/posts/` تولید می‌شود.
- هنگام انتشار، پوشه `fa` را هم همراه `index.html`، پوشه `assets` و فایل‌های نقشه سایت بارگذاری کنید. در GitHub Pages مسیر انتشار باید پوشه حاوی همین فایل‌ها باشد.
- آدرس‌های canonical، hreflang و sitemap بر اساس دامنه `vynor.ir` تنظیم شده‌اند؛ اگر دامنه عوض شد، این آدرس‌ها را نیز اصلاح کنید.

## عکس پروفایل
- عکس فعال سایت `assets/avatar.jpg` است و هر دو زبان از همان فایل استفاده می‌کنند.
- فایل `assets/avatar.svg` نیز همین عکس را به‌صورت داخلی نگه می‌دارد تا ارجاع‌های قدیمی به آواتار، نشان قبلی را نمایش ندهند. هنگام تعویض بعدی عکس، این نسخه سازگار با مسیر قدیمی را نیز به‌روز کنید.
- آدرس عکس و CSS در هر دو صفحه پارامتر نسخه دارند؛ پس از تغییر آن‌ها، مقدار `v` را به‌روز کنید تا مرورگر نسخه تازه را دریافت کند.
- کادر نمایش حداکثر ۲۶۰ × ۲۶۰ پیکسل و مربعی با گوشه‌های گرد است. برای عکس‌های بعدی، تصویر مربع ۵۲۰ × ۵۲۰ پیکسل یا بزرگ‌تر و حجم حدود ۲۰۰ کیلوبایت یا کمتر پیشنهاد می‌شود.
- عکس فعلی بدون تغییر فایل اصلی ذخیره شده است؛ CSS کادر آن را با تمرکز بر چهره تنظیم می‌کند. محل کادر با `object-position` در قانون `.avatar` قابل تنظیم است.
- هنگام تعویض عکس، فایل جدید را با نام `avatar.jpg` در پوشه `assets` قرار دهید. پسوند باید با فرمت واقعی عکس مطابقت داشته باشد.

## ۱) آپلود روی Liara (ابrador سرویس استاتیک)
1. وارد پنل [liara.ir](https://liara.ir) شوید و وارد کنسول شوید.
2. از منوی **Create App** گزینه **Static Site** (سایت استاتیک) را انتخاب کنید.
3. یک نام برای اپ انتخاب کنید (مثلاً `vynor`) و پلن مورد نظر را بزنید.
4. محتویات همین پکیج (همه‌ی فایل‌ها و پوشه `assets`) را در ریشه‌ی پروژه قرار دهید. می‌توانید:
   - با **Liara CLI** دیپلوی کنید:
     ```bash
     npm install -g @liara/cli
     liara login
     liara deploy --app vynor --port 80
     ```
     (فایل‌ها را در یک پوشه خالی باز کنید و داخل همان پوشه دستور را اجرا کنید.)
   - یا فایل زیپ را در بخش آپلود/دیسک اپ قرار دهید و از حالت فشرده خارج کنید.
5. در بخش **Domains** دامنه `vynor.ir` را به اپ اضافه کنید.
6. DNS:
   - رکورد **A** برای `@` → به IP اپلیکیشن Liara
   - رکورد **CNAME** برای `www` → به آدرس اپ (مثلاً `vynor.liara.run`)
7. پس از صدور SSL رایگان، سایت روی `https://vynor.ir` در دسترس است.

## ۲) آپلود روی هاست cPanel / DirectAdmin
1. وارد cPanel یا DirectAdmin شوید.
2. **File Manager** را باز کنید و به پوشه `public_html` (در DirectAdmin: `public_html` دامنه) بروید.
3. فایل زیپ را با **Upload** آپلود کنید، سپس راست‌کلیک → **Extract** در همان پوشه.
4. مطمئن شوید `index.html` مستقیماً داخل `public_html` باشد (نه داخل یک زیرپوشه‌ی اضافه).
5. دسترسی پوشه‌ها را روی `755` و فایل‌ها را روی `644` تنظیم کنید.
6. SSL رایگان (Let's Encrypt / AutoSSL) را از بخش Security فعال کنید.

## ۳) تنظیمات DNS
- اگر هاست شما IP اختصاصی دارد: رکورد **A** برای `@` و `www` روی IP هاست.
- اگر فقط آدرس دارد: رکورد **CNAME** برای `www` به دامنه اصلی.
- TTL را روی مقدار پیش‌فرض (مثلاً ۳۶۰۰) بگذارید؛ انتشار DNS معمولاً بین چند دقیقه تا ۲۴ ساعت طول می‌کشد.
- برای سرعت بیشتر می‌توانید کلودفلر (Cloudflare) را جلوی سایت قرار دهید (Proxy روی حالت نارنجی).

## ۴) شخصی‌سازی
- متن‌ها و لینک‌های شبکه‌های اجتماعی در `index.html` قابل ویرایش‌اند (بخش Contact).
- ایمیل در دکمه Copy Email داخل `index.html` (`data-email`) و در `mailto:` قرار دارد.
- رنگ‌ها به‌صورت متغیر CSS در ابتدای `assets/style.css` تعریف شده‌اند.
- تایم‌لاین سوابق کاری در بخش Experience کاملاً قابل ویرایش است.
