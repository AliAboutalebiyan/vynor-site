# vynor.ir — Ali Aboutalebiyan Profile

سایت استاتیک و کاملاً مستقل (بدون وابستگی به CDN خارجی) برای برند **vynor** — علی ابوطالبیان.

## ساختار فایل‌ها

```
assets/
  style.css

README.md
```

## ۱) آپلود روی Liara (ابrador سرویس استاتیک)
1. وارد پنل [liara.ir](https://liara.ir) شوید و وارد کنسول شوید.
2. از منوی **Create App** گزینه **Static Site** (سایت استاتیک) را انتخاب کنید.
3. یک نام برای اپ انتخاب کنید (مثلاً `vynor`) و پلن مورد نظر را بزنید.
4. محتویات همین پکیج (همه‌ی فایل‌ها و پوشه `assets`) را در ریشه‌ی پروژه قرار دهید. می‌توانید:
   - با **Liara CLI** دیپلوی کنید:
     ```bash
     npm install -g @liara/cli
     liara login
     liara deploy --app vynor --port 80
     ```
     (فایل‌ها را در یک پوشه خالی باز کنید و داخل همان پوشه دستور را اجرا کنید.)
   - یا فایل زیپ را در بخش آپلود/دیسک اپ قرار دهید و از حالت فشرده خارج کنید.
5. در بخش **Domains** دامنه `vynor.ir` را به اپ اضافه کنید.
6. DNS:
   - رکورد **A** برای `@` → به IP اپلیکیشن Liara
   - رکورد **CNAME** برای `www` → به آدرس اپ (مثلاً `vynor.liara.run`)
7. پس از صدور SSL رایگان، سایت روی `https://vynor.ir` در دسترس است.

## ۲) آپلود روی هاست cPanel / DirectAdmin
1. وارد cPanel یا DirectAdmin شوید.
2. **File Manager** را باز کنید و به پوشه `public_html` (در DirectAdmin: `public_html` دامنه) بروید.
3. فایل زیپ را با **Upload** آپلود کنید، سپس راست‌کلیک → **Extract** در همان پوشه.
4. مطمئن شوید `index.html` مستقیماً داخل `public_html` باشد (نه داخل یک زیرپوشه‌ی اضافه).
5. دسترسی پوشه‌ها را روی `755` و فایل‌ها را روی `644` تنظیم کنید.
6. SSL رایگان (Let's Encrypt / AutoSSL) را از بخش Security فعال کنید.

## ۳) تنظیمات DNS
- اگر هاست شما IP اختصاصی دارد: رکورد **A** برای `@` و `www` روی IP هاست.
- اگر فقط آدرس دارد: رکورد **CNAME** برای `www` به دامنه اصلی.
- TTL را روی مقدار پیش‌فرض (مثلاً ۳۶۰۰) بگذارید؛ انتشار DNS معمولاً بین چند دقیقه تا ۲۴ ساعت طول می‌کشد.
- برای سرعت بیشتر می‌توانید کلودفلر (Cloudflare) را جلوی سایت قرار دهید (Proxy روی حالت نارنجی).

## ۴) شخصی‌سازی
- متن‌ها و لینک‌های شبکه‌های اجتماعی در `index.html` قابل ویرایش‌اند (بخش Contact).
- ایمیل در دکمه Copy Email داخل `index.html` (`data-email`) و در `mailto:` قرار دارد.
- رنگ‌ها به‌صورت متغیر CSS در ابتدای `assets/style.css` تعریف شده‌اند.
- تایم‌لاین سوابق کاری در بخش Experience کاملاً قابل ویرایش است.
